# Solace

## 概述

Solace 是一款完全离线的本地图片与视频浏览应用。不联网、无账号、不上传，把设备里的照片和视频整理成自定义的图集与视频墙。

浏览的基本单位是**作品**：可以是一组图片加短视频，也可以是一段长视频。**上下滑动切换作品，左右滑动查看作品内媒体**；图片可缩放，短视频自动播放，长视频带播放控制与进度记忆。

设计原则：

- **本地优先**：原地读取媒体，只写本地数据库，不移动、不上传原始文件。
- **隐私默认**：不声明网络权限，无统计、无广告、无账号。
- **观看优先**：整理服务于浏览，最终呈现为一条顺滑的作品流。
- **用户定义**：图集、作品编排、封面与标签都由用户决定，不做算法推荐。

参考与取舍：

- 管理参考 **Emby / Jellyfin**：图集、标签、搜索筛选、播放进度；不做服务端、多用户、转码。
- 浏览参考 **抖音 / TikTok**：全屏竖向作品流、左右翻阅、手势；不做推荐、社交、在线内容。

## 目标

**让本地影像整理得动、看得下去、隐私可验证。**

1. **隐私**：不声明 `INTERNET` 权限，飞行模式下全功能可用；可选应用锁与私密图集。
2. **管理**：扫描本地媒体并增量索引，支持按文件夹导入；图集与视频墙、标签、搜索筛选、封面与排序。
3. **作品**：支持「多图 + 短视频」或「单长视频」，媒体可排序，可属于多个图集；删除作品不删源文件。
4. **浏览**：全屏上下滑切换作品，作品内左右滑切换媒体，预加载相邻作品；图片缩放、短视频循环、长视频进度记忆。
5. **体验底线**：千级作品、万级媒体下保持流畅；Android 8.0+，支持深色模式与无障碍。

首版不做：云同步、账号、社交分享、在线内容、AI 打标、图片视频编辑、多端同步。
